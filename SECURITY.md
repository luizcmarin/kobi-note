# Segurança

A segurança e a privacidade do Kobi Note são prioridades. Não publique detalhes
de uma vulnerabilidade em uma issue ou em uma discussão pública.

## Como comunicar

Use o recurso privado de **Security Advisories** do repositório no GitHub para
comunicar a vulnerabilidade. Inclua:

- uma descrição clara do problema;
- os passos mínimos para reproduzi-lo;
- a versão ou o commit afetado;
- o impacto observado;
- uma sugestão de correção, se houver.

Não inclua dados pessoais, tokens, chaves privadas ou backups reais no relatório.

## Escopo

Relate problemas que possam causar execução de código, exposição de dados locais,
perda de registros, falhas no mecanismo offline ou comprometimento da publicação.
Problemas de conteúdo e sugestões de produto devem usar uma issue comum.

A equipe confirmará o recebimento, investigará o relato e informará a correção ou a
mitigação aplicável quando isso puder ser feito com segurança.
