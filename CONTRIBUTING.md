# Contribuindo

Obrigado por ajudar a melhorar o Kobi Note.

## Antes de propor uma mudança

1. Procure uma issue existente ou abra uma nova para explicar o problema.
2. Para uma falha de segurança, siga o procedimento privado de [SECURITY.md](SECURITY.md).
3. Mantenha a proposta pequena e descreva o comportamento esperado.

## Pull requests

- explique o motivo e o efeito da mudança;
- inclua testes para comportamento novo ou corrigido;
- confirme que `bun run check` passa no monorepo de origem;
- descreva qualquer alteração visual ou de dados;
- não inclua tokens, chaves, backups pessoais ou arquivos de máquina.

Este repositório é o artefato publicado do Kobi Note. Alterações de código devem
ser feitas no monorepo de origem e publicadas por meio do processo do projeto.
