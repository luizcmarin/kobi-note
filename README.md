# Kobi Note

O Kobi Note é um aplicativo web instalável para anotações, estudo, criatividade,
finanças e preparo pessoal.

Acesse a versão publicada em <https://note.luizcmarin.com.br/>.

Para instalar no Android, no iPhone ou no computador, siga o passo a passo em
<https://note.luizcmarin.com.br/instalar.html>.

## Características

- funciona offline depois do primeiro carregamento;
- guarda os registros localmente no aparelho;
- pode ser instalado como aplicativo no navegador;
- inclui editor de texto, acervo curado e módulos de consulta;
- não exige uma conta para o uso local.

A conexão é necessária para carregar a versão mais recente e para receber o acervo
publicado. O uso cotidiano continua disponível sem conexão quando os arquivos e os
dados já estiverem em cache.

## Privacidade e dados

Os registros pessoais ficam no armazenamento local do navegador. Eles não são
enviados ao repositório público nem fazem parte do acervo publicado.

Limpar os dados do navegador, remover a instalação ou trocar de aparelho pode
apagar registros locais. Use a função de backup do aplicativo antes de fazer uma
operação desse tipo.

Leia [SECURITY.md](SECURITY.md) para comunicar problemas de segurança.
